## 🌌 스토리 및 세계관
일론 머스크의 **X 코퍼레이션**은 심우주(지구-화성 간 전진 궤도)에 인류 사상 최대 규모의 **초지능 오비탈 슈퍼 데이터센터 (X-AeroNet)**를 건설했습니다.  
이 데이터센터는 인류의 우주 개척, 스타링크 통신망, 차세대 분산 인공지능을 총괄하는 핵심 전략 거점입니다.

그러나 우주 데이터 패권을 탈취하려는 **적대적 신디케이트 공습 함대**가 대규모 전단을 이끌고 데이터센터 침공을 감행했습니다!

플레이어는 **수비팀(SpaceX 방어군)** 또는 **공격팀(신디케이트 공습 함대)** 중 진영을 직접 선택하여 실시간으로 3D 온라인 대전을 펼치게 됩니다.

## ⚔️ 진영 선택 시스템 (FACTION SYSTEM)

### 🛡️ 1. 수비팀: 머스크의 SpaceX 방어군 (DEFENSE)
- **주요 목표**: 머스크의 X 우주 데이터센터를 사수하고 피해 발생 시 긴급 복구
- **전투함**: **CyberHawk Mk-IX** (고기동 사이안 블루 스텔스 요격기)
- **스킬 및 무장**:
  - **트윈 고속 플라즈마 레이저 [좌클릭]**: 빠른 연사력의 에너지 볼트
  - **호밍 마이크로 미사일 [우클릭 / F]**: 적 요격기 및 기지로 날아오는 적 어뢰를 자동 추적 요격
  - **나노봇 기지 수리 빔 [R 키]**: 데이터센터 320m 반경(녹색 홀로그램 링) 내에서 기지 체력 복구
  - **EMP 펄스 충격파 [X 키]**: 접근 중인 모든 적 어뢰를 일제히 공중 폭파하고 주변 적 함선 기절
  - **스타링크 방어 위성 배치 [U 키]**: 데이터센터 주변을 공전하며 침입자를 자동 사격하는 방어 드론

### ⚔️ 2. 공격팀: 신디케이트 공습 함대 (ATTACK)
- **주요 목표**: 머스크의 우주 데이터센터를 폭발물과 레이저로 완전 폭파 파괴
- **전투함**: **Syndicate Void Siege Bomber** (중장갑 크림슨 레드/오렌지 공성 폭격기)
- **스킬 및 무장**:
  - **대구경 헤비 디스럽터 레이저 [좌클릭]**: 강력한 타격력으로 데이터센터와 수비기를 직접 파괴
  - **공성 대형 폭발 어뢰 [우클릭 / F]**: 데이터센터를 조준하여 220 데미지의 거대 폭발 탄두 발사
  - **데이터 코어 해킹 & 쉴드 흡수 [R 키]**: 데이터센터 코어 근접 시 기지 쉴드를 흡수 해킹하고 자원 약탈
  - **클러스터 폭발탄 4연발 살포 [X 키]**: 4발의 확산 폭발탄을 일제히 투하하여 데이터센터 쉴드 및 수비군 광역 폭파

## 🌐 실시간 온라인 멀티플레이 (MULTIPLAYER)

Node.js 내장 WebSocket 서버 기반의 초저지연 실시간 멀티플레이를 지원합니다:
- **실시간 기체 동기화**: 다른 플레이어의 3D 함선 위치, 회전, 속도, 체력이 60fps 부드러운 보간(Lerp)으로 화면에 표시됩니다.
- **실시간 무장 동기화**: 상대방이 쏘는 레이저, 발사한 대형 어뢰, 폭파 효과가 전 플레이어 화면에 실시간 렌더링됩니다.
- **상호 요격 및 공방전**: 공격팀이 발사한 대형 어뢰를 수비팀 플레이어가 레이저로 공중 요격할 수 있습니다.
- **자동 AI 봇 지원**: 다른 플레이어가 없어도 반대편 진영의 AI 전투기가 자동 스폰되므로 1인 플레이 및 다인 플레이 모두 원활하게 진행됩니다.

## 🎮 조작법 가이드

| 조작 키 | 기능 | 설명 |
| :--- | :--- | :--- |
| **마우스 이동** | **기수 조준 (Gimbal Aim)** | 공격 조준선이 마우스 커서를 실시간 추적하여 레이저 집속 발사 |
| **마우스 휠 스크롤** | **FOV 시야각 줌** | 35° 망원 정밀 조준 ~ 110° 초광각 전장 시야 조절 |
| **마우스 휠 클릭** | **FOV 리셋** | 기본 시야각(65°)으로 즉시 초기화 |
| **W / S** | **엔진 가속 / 감속** | 전진 추진 및 역추진 감속 |
| **A / D** | **좌우 이동 (Strafe)** | 측면 버니어 추진체 기동 |
| **Q / E** | **롤 회전 (Roll)** | 기체 좌/우 회전 |
| **Shift** | **애프터버너 부스터** | 순간 가속 추진 |
| **Space / 좌클릭** | **주무장 레이저** | 트윈 레이저(수비) / 대구경 디스럽터(공격) — 키보드 Space 또는 마우스 좌클릭으로 발사 |
| **우클릭 / F** | **보조 미사일/어뢰** | 호밍 미사일 요격(수비) / 공성 폭발 어뢰(공격) |
| **C** | **하강 (Down)** | 기체 하강 버니어 추진 |
| **Z** | **상승 (Up)** | 기체 상승 버니어 추진 |
| **R** | **기지 상호작용** | 나노봇 기지 수리(수비) / 기지 쉴드 해킹 및 약탈(공격) |
| **X** | **특수 스킬** | EMP 충격파 방출(수비) / 클러스터 폭발탄 4연발(공격) |
| **U** | **엔지니어링 상점** | 기체 업그레이드 및 스타링크 위성 배치 |
| **V** | **시점 전환** | 1인칭 조종석 뷰 ↔ 3인칭 추적 뷰 전환 |
| **P / ESC** | **일시 정지** | 게임 일시 정지 및 진영 전환 |
| **M** | **음소거 토글** | 사운드 온/오프 |

## 📡 배포 가이드

### 🚀 온라인 배포 (권장)

#### Option 1: Cloudflare Pages (추천) ⭐⭐⭐
**가장 간단한 방법 - 5분 내 배포**

1. https://dash.cloudflare.com 로그인
2. **Pages** → **Create a project** → **Connect to Git**
3. GitHub 연결 후 `matzipcom/War-of-SpaceX` 선택
4. 설정:
   - Build command: (빈칸)
   - Build output directory: `public`
5. **Save and Deploy** 클릭

완료! 배포 URL: `https://war-of-spacex.pages.dev`

#### Option 2: Railway + Cloudflare Pages (최적) ⭐⭐⭐⭐
프론트엔드는 Cloudflare Pages, 백엔드는 Railway에 배포하여 완벽한 멀티플레이 지원

[상세 배포 가이드](./DEPLOYMENT_GUIDE.md) 참고

### 💻 로컬 서버 실행

```bash
# 저장소 클론
git clone https://github.com/matzipcom/War-of-SpaceX.git
cd War-of-SpaceX

# 서버 실행
node server.js

# 브라우저 접속
http://localhost:8080
```

## 🌐 온라인 플레이 방법

배포 후 게임 시작:

1. **배포 URL 접속** (예: https://war-of-spacex.pages.dev)
2. **팀 선택**: DEFENSE 또는 ATTACK
3. **플레이어명 입력** (선택사항)
4. **게임 시작**

### 멀티플레이 테스트
- 같은 URL을 2개 이상의 브라우저 탭/창에서 열기
- 각각 다른 팀 선택
- 실시간 3D 대전 시작!
